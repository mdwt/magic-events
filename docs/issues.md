# Issues

The working list for version 1, as three tables: what is still being worked on, what is noted for phase 2, and what
is closed. One row per issue. A row says what the issue is and what was decided or built. Where a decision changes how
the system works, it is also in the document that owns the subject.

**Status:** `In progress` being built now · `To do` decided, and starts when the work it waits on is committed ·
`Phase 2` decided or noted, and not part of version 1 · `Closed` decided, and built where it needed building.

| 97 | No data may be lost, even when a source fails or is read badly | Discovery, Data processing | In progress | A failed fetch already changes nothing, and a listing that disappears loses its link only after the configured number of complete runs without it.
